# Windows

Snapper is pre-alpha and does not yet provide a supported screen-capture workflow. There is no Snapper-specific permission prompt to configure yet.

Windows privacy controls mostly apply to Microsoft Store apps; desktop apps may not appear in those lists. If a future capture build reports an access error, check the app's release notes and the official [Windows app permissions guidance](https://support.microsoft.com/en-us/windows/apps/app-permissions) before changing device-wide privacy settings. Do not assume that enabling the camera or microphone settings controls desktop screenshot capture.
